　　　　　　　　　　　　　　　　　　　礼物（已发表，见于《微型小说选刊》）<br>
　　今天是每月一次的家庭聚会日，地点定在月映楼。晚上八点，2号包厢内，除陈光外，其他人都到了。<br>
　　工作一整天，众人的肚子早已饿得咕咕叫，但碍于刘老还未动筷子，大家也只好磕着瓜子，强忍着饥饿，你一言我一语地聊起了家常。小一点的孩子聚在一起玩打手背的游戏，偶尔抓起桌上的糖果充饥。<br>
　　半小时后，餐厅门口出现了一个身穿黑色棉服、围着红色围巾的男孩。他不住地搓着通红的手背，眼睛左右瞟着，像是在寻找什么。等发现空位，赶忙将身旁的自行车推过去，踢开脚撑，小心翼翼放稳车子。这才满意地小跑进餐厅。<br>
　　自行车右边的刹车闸坏了，车筐也锈迹斑斑。这车是十八岁生日时，父母送给他的礼物，因为是品牌，当时花了500块。要知道，他早相中这辆车了，只是因为价格太高，迟迟没下手。收到礼物的那天，他一晚上没睡好觉。<br>
　　包厢门缓缓推开，男孩脸上挂着歉意：“刚才有点事，来晚了。”大家没有责怪他，表面笑嘻嘻地说不要紧，心里想着终于能开饭了。只有穿卡其色毛衣的女人表情古怪。<br>
　　等刘老一拿筷子，十几双筷子全都跟着动了起来。仅仅几分钟，盘里的红烧肉便一扫而空。陈光也忙着往嘴里送饭，像狩猎的野兽一般盯着桌上的鸭肉、鸡肉……<br>
　　“光儿，你现在干啥工作啊？”众人如狼似虎地吃着饭菜，刘老却放下筷子，缓缓开口。饱经风霜的嗓音加上舒卷的眉头，衬得他格外慈爱。他是陈光的姥爷，今年80多岁了，身子骨很是硬朗。<br>
　　陈光放下筷子，费力地将嘴里的肉咽下去，挠头笑着说自己是个网络小说家。怕刘老听不清，他大声重复了一遍。<br>
　　“网络小说家是啥？”刘老挠着头发，眼神里透露出一丝迷茫。大半辈子的经历，见过当老师的、当警察的，甚至当心理咨询师的，但网络小说家这个职业，他还真没听说过。<br>
　　没等陈光解释，穿卡其色衣服的女人抢先说道：“什么网络小说家，就是个浪费时间、啥钱也不挣的工作，天天蹲在电脑前，敲着键盘……”听完这话，房间里的所有人都愣住了，他们的眼神在陈光和那个女人之间飘荡。<br>
　　陈光愣了愣，朝着女人说：“妈，我这是正经职业，尽管现在不赚钱，但是……”<br>
　　“但是将来会赚钱，对吗？这话我两年前就听过了。醒醒吧，别做白日梦了，你就不能务实……”一长串话像断线珠子似的散落，重重砸在陈光的心里，使他的心上又多了几个深浅不一的坑。<br>
　　陈光不想反驳了，他强忍着泪水，低头扒着碗里的米饭。他已经习惯了。尽管众人不说，他也知道他们心里在想什么。“没出息”“白上大学了”“他是不是得了幻想症”。<br>
　　一小时前，他还蹲在电脑前写小说，用键盘敲出动人的故事，时不时为几个读者的评论而暗自窃喜。而现在，他坐在饭桌前，吃着已经凉了的饭菜。外面，正下着鹅毛大雪。<br>
　　刘老没有开口，只是若有所思地看着这一幕。<br>
　　深夜，众人寒暄一阵，各自离去。房间里只剩下刘老、穿卡其色衣服的女人和陈光。女人率先开口：“爸，我们先走了。”说着她推了推旁边的陈光，示意他站起来。尽管不情愿，陈光还是按照母亲的意思做了。<br>
　　“光儿先走吧，我和你母亲聊聊天。”刘老再次开口，语气里多了一些严肃。陈光看了看母亲，又看了看姥爷，点头答应。房间里，只剩下一对父女。
女人的皱纹缩成一团，她在刘老对面坐下，盯着剩下的半杯橙汁：“爸，您知道，这条路不好走。”<br>
　　“不好走的路，也有人走过，不是吗？而且这一走就是十年。”刘老叹了口气，接着说，“我不懂网络小说家是啥，但只要孩子喜欢，就让他试试吧。”<br>
　　女人张开嘴巴，想要反驳，却没有发出一丝声响。她索性扭过头看起窗外的大雪。昏黄的灯光下，玻璃窗上映着一张满是泪痕的脸庞。<br>
　　几十年前，和陈光一般大的年纪，她爱上了画漫画，为了买画纸，整天啃馒头，嚼咸菜……考上高中的时候，父亲送给了她一套画笔。<br>
　　外面的雪停了，只留下一条雪白色的毛毯，像是证明自己曾降临这世间。<br>
　　第二天清晨，陈光发现电脑旁多了一个崭新的键盘，是他喜欢却没舍得买的那款。<br>
